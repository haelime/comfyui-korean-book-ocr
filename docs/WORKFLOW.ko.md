# 워크플로우 사용법

## 전체 흐름

```text
책 사진 + 선택 마스크
  → 한국어 OCR
  → Qwen 오타·맞춤법 2차 교정
  → 직접 수정 및 수동 꾸밈
  → 글꼴·색상·크기 적용
  → 미리보기와 PNG 저장
```

## 1. OCR 영역 선택

1. `Load Image`에서 책 사진을 선택합니다.
2. 사진 전체를 OCR하려면 마스크를 비워 둡니다.
3. 일부만 OCR하려면 노드를 우클릭해 `Open in Mask Editor`를 열고 해당 문장이나 문단만 흰색으로 칠합니다.
4. Queue를 실행합니다.

## 2. Qwen 정밀 교정

`로컬 AI OCR 오타·맞춤법 교정`은 기본 `정밀` 모드에서 OCR 원문을 글자 단위와 문맥 단위로 두 차례 검토합니다. 꾸밈을 추천하거나 Markdown 기호를 자동으로 넣지 않습니다.

노드 출력은 두 가지입니다.

- `교정_텍스트`: 오타와 맞춤법을 검토한 본문
- `OCR_원문`: AI 처리 전 본문

`자동_교정`을 끄면 OCR 원문이 그대로 전달됩니다.

## 3. 직접 수정과 수동 꾸밈 문법

`OCR 텍스트 수정 → 이미지`의 `수정_텍스트`에서 최종 내용을 손봅니다. `AI 교정본으로 재설정` 버튼을 누르면 직접 수정한 내용을 Qwen 교정 결과로 되돌립니다.

```markdown
__붉은 색연필 밑줄__[^1]
**굵게**
*이탤릭*
~~형광펜~~

[^1]: 밑줄에 연결할 작은 붉은 댓글
```

밑줄·굵게·이탤릭·형광펜 기호는 여러 줄에 걸쳐도 됩니다.

```markdown
__첫 줄에서 시작한 밑줄이
둘째 줄까지 이어집니다.__
```

각주 댓글은 밑줄 바로 뒤에 `[^이름]`을 붙이고 본문 아래에 `[^이름]: 댓글`을 씁니다. 꾸밈 문법은 서로 중첩하지 마세요.

검토 결과 `**굵게**`를 추가했습니다. 제목, 목록, 링크, 코드 문법은 짧은 책 문장 이미지에서 효용이 작고 원문의 기호와 충돌할 수 있어 지원하지 않습니다.

## 4. 디자인 설정과 미리보기

`글꼴·색상·크기 설정 + 미리보기`에서 본문/댓글 글꼴과 크기, 이미지 너비, 여백, 줄 간격, 본문색, 붉은 밑줄색, 형광펜색, 배경색을 조절합니다.

색상 아래의 `색상표 열기` 버튼으로 색을 고르고 Queue를 실행하면 `스타일_미리보기` 출력에서 결과를 확인할 수 있습니다.

## 5. 저장

최종 이미지는 `Preview Image`에서 확인되고 `Save Image`가 ComfyUI의 기본 출력 폴더에 `korean_book_quote` 이름으로 저장합니다.

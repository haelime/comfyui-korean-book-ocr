# 워크플로우 사용법

## 전체 흐름

```text
책 사진 + 선택 마스크
  → 한국어 OCR
  → Qwen 오타·맞춤법 2차 교정
  → 직접 수정 및 수동 꾸밈
  → 글꼴·색상·크기 적용
  → 미리보기와 PNG 저장
```

## 1. OCR 영역 선택

1. `Load Image`에서 책 사진을 선택합니다.
2. 사진 전체를 OCR하려면 마스크를 비워 둡니다.
3. 일부만 OCR하려면 노드를 우클릭해 `Open in Mask Editor`를 열고 해당 문장이나 문단만 흰색으로 칠합니다.
4. Queue를 실행합니다.

## 2. Qwen 정밀 교정

`로컬 AI OCR 오타·맞춤법 교정`은 기본 `정밀` 모드에서 OCR 원문을 글자 단위와 문맥 단위로 두 차례 검토합니다. 꾸밈을 추천하거나 Markdown 기호를 자동으로 넣지 않습니다.

노드 출력은 두 가지입니다.

- `교정_텍스트`: 오타와 맞춤법을 검토한 본문
- `OCR_원문`: AI 처리 전 본문

`자동_교정`을 끄면 OCR 원문이 그대로 전달됩니다.

## 3. 직접 수정과 수동 꾸밈 문법

`OCR 텍스트 수정 → 이미지`의 `수정_텍스트`에서 최종 내용을 손봅니다. `AI 교정본으로 재설정` 버튼을 누르면 직접 수정한 내용을 Qwen 교정 결과로 되돌립니다.

```markdown
__붉은 색연필 밑줄__[^1]
**굵게**
*이탤릭*
~~형광펜~~

[^1]: 밑줄에 연결할 작은 붉은 댓글
```

밑줄·굵게·이탤릭·형광펜 기호는 여러 줄에 걸쳐도 됩니다.

```markdown
__첫 줄에서 시작한 밑줄이
둘째 줄까지 이어집니다.__
```

각주 댓글은 밑줄 바로 뒤에 `[^이름]`을 붙이고 본문 아래에 `[^이름]: 댓글`을 씁니다. 꾸밈 문법은 서로 중첩하지 마세요.

검토 결과 `**굵게**`를 추가했습니다. 제목, 목록, 링크, 코드 문법은 짧은 책 문장 이미지에서 효용이 작고 원문의 기호와 충돌할 수 있어 지원하지 않습니다.

## 4. 디자인 설정과 미리보기

`글꼴·색상·크기 설정 + 미리보기`에서 본문/댓글 글꼴과 크기, 이미지 너비, 여백, 줄 간격, 본문색, 붉은 밑줄색, 형광펜색, 배경색을 조절합니다.

색상 아래의 `색상표 열기` 버튼으로 색을 고르고 Queue를 실행하면 `스타일_미리보기` 출력에서 결과를 확인할 수 있습니다.

## 5. 저장

최종 이미지는 `Preview Image`에서 확인되고 `Save Image`가 ComfyUI의 기본 출력 폴더에 `korean_book_quote` 이름으로 저장합니다.

## 대량 작업 워크플로우

`korean_ocr_batch`는 사진마다 TXT 하나를 만들고, 수정한 TXT마다 PNG 하나를 만드는 2단계 워크플로우입니다.

### 1단계: 사진을 TXT로 만들기

1. `ComfyUI/input/대량_OCR_사진`에 JPG, JPEG, PNG, WebP, BMP 또는 TIFF 사진을 넣습니다.
2. `① 사진 폴더 → OCR 텍스트 파일`의 `실행`을 켭니다.
3. Queue를 누릅니다.
4. 결과는 `ComfyUI/output/korean_book_ocr/text`에 원본 사진과 같은 이름의 TXT로 저장됩니다.

기본값으로 Qwen 정밀 교정까지 적용됩니다. 사용하지 않으려면 `자동_맞춤법_교정`을 끄세요. Ollama 교정에 실패해도 OCR 원문은 TXT로 저장하고 작업 결과에 경고를 남깁니다. `기존_텍스트_보호`가 켜져 있으면 이미 만든 TXT를 건너뛰므로 사람이 수정한 내용을 잃지 않습니다.

### 중간 단계: TXT 직접 수정

생성된 TXT를 메모장이나 원하는 문서 편집기로 열어 오타와 줄바꿈을 확인합니다. 밑줄, 굵게, 이탤릭, 형광펜, 댓글 문법도 이때 직접 넣고 저장합니다.

### 2단계: TXT를 PNG로 만들기

1. ① 노드의 `실행`을 끕니다.
2. `글꼴·색상·크기 설정 + 미리보기`에서 디자인을 정합니다.
3. `② 텍스트 폴더 → 파일별 이미지`의 `실행`을 켭니다.
4. Queue를 누릅니다.
5. 결과는 `ComfyUI/output/korean_book_ocr/images`에 TXT와 같은 이름의 PNG로 저장됩니다.

사진을 하위 폴더로 나누면 TXT와 PNG도 같은 하위 폴더 구조로 정리됩니다. 처리 중 일부 파일에 오류가 나더라도 나머지 파일은 계속 처리하며 작업 결과에 오류 수를 표시합니다.

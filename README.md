# ComfyUI 한국어 책 OCR

소설책을 찍은 사진에서 원하는 부분 또는 전체를 한국어로 OCR하고, 로컬 Qwen으로 오타와 맞춤법만 교정한 뒤 직접 수정해 꾸민 이미지로 저장하는 ComfyUI 커스텀 노드입니다.

Qwen은 밑줄이나 형광펜을 추천하지 않습니다. 꾸밈은 사용자가 최종 편집 칸에서 직접 지정합니다.

## 주요 기능

- 마스크로 칠한 문단만 OCR하며, 마스크가 비어 있으면 사진 전체를 자동 사용
- 소설책 촬영본의 회전, 페이지 휨, 대비 보정
- 로컬 `qwen3:8b`가 OCR 오타와 맞춤법을 두 차례 검토
- AI 교정본과 OCR 원문을 모두 출력해 선택 가능
- 교정된 글을 노드 안에서 직접 수정한 뒤 바로 이미지로 변환
- 글꼴, 크기, 줄 간격, 본문색, 배경색, 밑줄색, 형광펜색 설정 및 미리보기
- 붉은 색연필 밑줄, 굵게, 이탤릭, 형광펜, 작은 붉은 필기 댓글 지원

## 가장 쉬운 Windows 설치

`uv`, Git, 별도의 Python은 필요하지 않습니다.

1. ComfyUI를 완전히 종료합니다.
2. 이 저장소 위쪽의 초록색 **Code** 버튼을 누르고 **Download ZIP**을 선택합니다.
3. ZIP 압축을 푼 폴더 전체를 `ComfyUI/custom_nodes/` 안에 넣습니다.
4. 폴더 안의 `install_windows.bat`을 더블클릭합니다.
5. 설치가 끝나면 ComfyUI를 다시 실행합니다.
6. 워크플로우 메뉴에서 `korean_ocr_to_image`를 엽니다.

설치 파일은 ComfyUI가 실제로 사용하는 Python을 찾아 OCR 패키지를 `pip`로 설치하고, 기본 워크플로우를 자동으로 복사합니다. 폴더 위치를 모르거나 오류가 나면 [Windows 설치 가이드](docs/INSTALL.ko.md)를 순서대로 따라 하세요.

## Qwen 로컬 교정 설치

OCR만 사용할 때는 Ollama가 없어도 됩니다. 오타·맞춤법 자동 교정을 사용하려면 [Ollama Windows 설치 페이지](https://ollama.com/download/windows)에서 Ollama를 설치한 뒤 `install_windows.bat`을 다시 실행하세요. 설치 파일이 `qwen3:8b` 모델 다운로드 여부를 묻습니다. 모델 크기는 약 5.2GB입니다.

직접 설치하려면 다음 명령을 한 번 실행합니다.

```powershell
ollama pull qwen3:8b
```

모든 교정은 기본적으로 내 PC의 `http://127.0.0.1:11434`에서 처리됩니다. 자동 교정이 필요 없으면 노드의 `자동_교정`을 끄세요.

## 사용 순서

1. `Load Image`에서 책 사진을 선택합니다.
2. 전체 사진을 OCR하려면 그대로 둡니다.
3. 일부 문단만 읽으려면 `Load Image`를 우클릭하고 `Open in Mask Editor`에서 원하는 곳을 흰색으로 칠합니다.
4. Queue를 실행하면 OCR과 Qwen 오타·맞춤법 교정이 진행됩니다.
5. `OCR 텍스트 수정 → 이미지`에서 교정 결과를 확인하고 직접 고칩니다.
6. 필요한 부분에 아래의 수동 꾸밈 문법을 넣고 다시 Queue를 실행합니다.
7. 결과는 `Preview Image`에서 보고 `Save Image`로 저장합니다.

## 수동 꾸밈 문법

```markdown
__붉은 색연필 밑줄__[^1]
**굵게**
*이탤릭*
~~형광펜~~

[^1]: 밑줄에 연결할 작은 붉은 손글씨 댓글
```

밑줄·굵게·이탤릭·형광펜은 여는 기호와 닫는 기호가 서로 다른 줄에 있어도 이어서 적용됩니다. 문법끼리는 중첩하지 마세요.

각주 댓글은 `__밑줄__[^이름]`처럼 밑줄 뒤에 표시하고, 본문 아래에 `[^이름]: 댓글`을 작성합니다. 각주 정의는 본문에서 빠지고 이미지 아래에 작은 붉은 글씨로 렌더링됩니다.

추가 문법을 검토해 `**굵게**`를 지원했습니다. 제목, 목록, 링크, 코드 문법은 짧은 책 문장 이미지에서 표시 효과가 작고 원문 기호와 충돌할 수 있어 지원하지 않습니다.

## 포함된 노드

- `마스크 영역 한국어 OCR`
- `로컬 AI OCR 오타·맞춤법 교정`
- `글꼴·색상·크기 설정 + 미리보기`
- `OCR 텍스트 수정 → 이미지`
- `한국어 OCR (PaddleOCR)`
- `한국어 텍스트 → 이미지`

## 소설책 촬영 권장값

- 평평한 페이지: `document_unwarp=false`
- 휘거나 사선으로 찍힌 페이지: `document_unwarp=true`
- 흐리거나 대비가 낮은 사진: `enhance_book_photo=true`
- 마스크 방향이 반대로 잡힐 때: `invert_mask=true`
- 양쪽 페이지의 읽기 순서가 섞일 때: 왼쪽과 오른쪽 페이지를 각각 잘라 처리

## 문제 해결

- `No module named paddleocr`: ComfyUI를 종료하고 `install_windows.bat`을 다시 실행합니다.
- Ollama 연결 오류: Ollama 앱을 실행하거나 `자동_교정`을 끕니다.
- 노드 입력 타입 오류: ComfyUI를 완전히 재시작하고 최신 `korean_ocr_to_image.workflow.json`을 다시 엽니다.
- 한글이 네모로 표시됨: 스타일 노드에서 `맑은 고딕` 등 한글 글꼴을 선택합니다.
- 첫 실행이 느림: PaddleOCR 모델을 처음 한 번 내려받는 정상 동작입니다.

더 자세한 해결 방법은 [Windows 설치 가이드](docs/INSTALL.ko.md)에 있습니다.

## 참고

- Windows에서는 `AUTO` 글꼴이 맑은 고딕을 우선 사용합니다.
- Windows CPU의 Paddle 3.3.x 오류를 피하기 위해 `enable_mkldnn=False`를 사용합니다.
- PaddleOCR 모델은 첫 OCR 실행 때 자동으로 다운로드됩니다.
